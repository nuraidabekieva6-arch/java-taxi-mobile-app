# 📱 Taxi Mobile Application (Java / Android UI)

Клиентское мобильное приложение для заказа такси, отслеживания водителя и управления поездками.

## 🚀 Основной функционал

 **Заказ такси:** Ввод маршрута (A ➔ B) с авторасчетом стоимости поездки.
 **Выбор класса:** Эконом, Комфорт, Бизнес.
 **Отслеживание статуса:** Отображение этапов («Поиск водителя», «Водитель в пути», «Завершен»).
 **Управление заказами:** Просмотр истории и активных поездок.
## 🛠 Технологический стек

**Язык программирования:** Java (JDK 17)
**Архитектура:** ООП, Инкапсуляция, Моделирование сущностей (Order, Driver, Client)
**Структуры данных:** List / ArrayList
