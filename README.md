# 🚕 Taxi Mobile Application (Java / Android)

Современное мобильное приложение для онлайн-заказа такси, выбора тарифов и отслеживания маршрутов поездок. Проект разработан на языке **Java** с оформлением интерфейса в фирменной тёмно-жёлтой гамме (**Dark / Yellow Theme**).
## 📱 Структура и экраны приложения (UI/UX)

Приложение состоит из 3 ключевых пользовательских сценариев:

1. **Экран оформления заказа (Форма подачи)**
   - Ввод адресов отправления («Откуда») и назначения («Куда»).
   - Интерактивная карта с отображением свободных автомобилей поблизости.
   - Быстрый выбор типа автомобиля и автоматический расчёт стоимости.

2. **Экран карты и дополнительных сервисов**
   - Тёмная карта с маршрутизацией и точками электрозаправок / геопозиции.
   - Быстрый выбор категории поездки или доставки: *Такси, Еда, Транспорт, Грузовой, Навигатор*.
   - Индикатор статуса и выбора тарифов.

3. **Экран выбора классов и тарифов**
   - **Эконом** *(от 150 ₽/км)*: Бюджетный вариант, стандартные авто, кондиционер.
   - **Комфорт** *(от 200 ₽/км)*: Оптимальный выбор, комфортные авто, климат-контроль, зарядка.
   - **Бизнес** *(от 450 ₽/поездка)*: Премиум-класс, кожаный салон, вода/пресса, профессиональный водитель.

## 🚀 Основной функционал

- 📍 **Формирование маршрута:** Ввод точек A ➔ B с автоматическим расчётом стоимости поездки.
- 🚖 **Гибкая система тарификации:** Поддержка нескольких классов обслуживания (Эконом, Комфорт, Бизнес).
- 🔄 **Отслеживание статуса заказа:** Жизненный цикл поездки («Поиск водителя», «Водитель в пути», «Поездка начата», «Завершён»).
- 📜 **Управление поездками:** Просмотр активных заказов и истории прошлых поездок.

## 🛠 Технологический стек

- **Язык программирования:** Java (JDK 17+)
- **Архитектура:** Объектно-ориентированное программирование (ООП), паттерн MVC
- **Пользовательский интерфейс:** Java Swing / Android UI Framework
- **Дизайн и прототипирование:** Figma (Dark/Yellow Theme)
